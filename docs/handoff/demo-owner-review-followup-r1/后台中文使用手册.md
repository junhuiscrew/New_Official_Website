# 骏辉全球官网后台中文使用手册（Demo R2）

版本：Demo Owner Review Follow-up R1  
适用环境：`https://admin-demo.junhuiscrewbarrel.com/`  
面向人员：公司中国员工、内容维护人员、审核人员  
当前限制：这是 Demo 使用手册。Privacy 尚未发布，RFQ 提交仍关闭，全站仍受 `noindex/no-store` 保护。

## 建议操作顺序

每次维护都按下面顺序操作，可以减少误发布和中英文错配：

1. 先确认自己进入的是 `admin-demo.junhuiscrewbarrel.com`，不要在生产环境试操作。
2. 先到“媒体资源库”上传图片或文件，填写中文和英文 Alt、标题、图注。
3. 再维护产品、文章、案例、FAQ、下载资料或首页模块。
4. 中文和英文分开检查；切换语言前先保存当前语言。
5. 先保存为草稿，再刷新或重新打开，确认刚才的内容已回读。
6. 用“预览”检查标题、图片、链接、移动端和关联内容。
7. 需要发布时，由具备发布权限的人员审核并发布；不要把“保存”当成“发布”。
8. 发布后重新打开前台页面检查。Demo 中不要发布 Privacy，也不要开启 RFQ。

## 1）后台登录与入口说明

1. 打开 `https://admin-demo.junhuiscrewbarrel.com/`。
2. 输入分配给自己的邮箱和密码，点击“安全登录”。不要共用账号，也不要把密码写入文档、聊天截图或浏览器公开笔记。
3. 登录后左侧出现后台菜单。右上或侧栏底部显示当前登录人员。
4. 需要查看前台时，可点击“查看演示站”，前台地址应保持为 `https://demo.junhuiscrewbarrel.com/`。
5. 如果看到 401、登录页反复跳转或权限不足，先重新登录；仍失败时联系管理员检查账号状态和角色，不要反复新建账号。

## 2）页面结构与菜单说明

后台左侧菜单按工作类型分组：

- “网站总览”：查看前台页面、语言、发布与 SEO 状态。
- “首页编排”：维护首页 14 个既定模块以及 Hero 轮播。
- “工作台 / 演示素材”：查看 Demo 资源和演示环境说明。
- “产品与目录”：进入产品、分类、规格、材料、应用、工艺技术、解决方案等维护入口。
- “客户案例 / 知识文章 / 常见问题 / 作者与专家”：维护内容体系。
- “企业资料与制造能力”：维护公司资料、能力、设备、证书和专利等公开内容。
- “下载资料”：维护可公开下载的 PDF 等资料。
- “媒体资源库”：上传图片/文件并维护双语元数据。
- “询盘中心”：查询已有询盘；当前 Demo 不会创建正式询盘。
- “网站语言 / 用户管理 / 角色权限”：系统管理入口，仅授权人员使用。
- “产品总列表 SEO / 联系页面 SEO / 询价页面 SEO”：维护固定页面的 SEO 文案。
- “隐私版本”：管理隐私内容；当前 Demo 不得发布。

页面中通常分为“列表、编辑表单、状态、操作按钮”四部分。先在列表中选择已有记录，再修改表单。任何提示“重新读取实际值”的页面，都应在保存后等待回读成功再离开。

## 3）首页内容如何修改

入口：左侧“首页编排”。

### 修改现有首页模块

1. 在顶部选择“简体中文”或“English”。两种语言分别维护。
2. 左侧选择一个首页模块。现有首页固定保留 14 个模块，不要为了改内容删除整个结构。
3. 可调整模块顺序、显示/隐藏、允许的视觉样式，以及部分模块引用的已发布产品。
4. 点击“保存草稿”。看到 revision 更新和回读成功后，再点击“打开完整预览”。
5. 预览无误后，具备权限的人员才点击“应用布局”。

### 修改首页轮播图

1. 进入“首页编排”，选择 `Hero 首页主视觉`。
2. 在“Banner Slider 轮播图”区域点击“新增轮播项”。最多 5 张。
3. 逐项填写：图片、主标题、副标题、按钮文案、跳转链接、启用状态。
4. 图片只能选择媒体库中“公开、已就绪、图片类型”的记录。
5. 按钮文案和链接必须同时填写或同时留空；链接只写本站路径，例如 `/zh-cn/products/`，不要粘贴外站地址或脚本。
6. 用上移、下移按钮调整播放顺序；列表顺序就是前台顺序。
7. 关闭“在前台启用这一项”后，该项仍留在草稿中，但公开首页不会显示。
8. 删除前会出现确认框。删除是对当前语言草稿操作，保存前可刷新页面放弃更改。
9. 中文完成后切到 English，分别填写英文标题、副标题、按钮和 `/en/.../` 链接。
10. 保存草稿后用下方认证预览检查，再应用。前台会自动播放，也可用箭头、编号和暂停按钮切换。

本轮四张图片和文案均标记为 Demo 素材，正式上线前必须用批准的真实资料替换。

## 4）产品如何新增/修改

入口：“产品与目录”→“产品”。

1. 新增前先确认产品分类、需要关联的材料/应用/工艺是否已存在。
2. 点击新增产品，填写内部识别字段和公开字段。Slug 使用简短英文小写和连字符；创建后不要随意修改，以免旧链接失效。
3. 分别填写中文和英文名称、摘要、正文及页面所需字段。
4. 选择主图、图库、分类及真实存在的关联内容。
5. 先保存草稿，再重新选择该记录，确认保存值已经回填。
6. 检查前台预览、图片、H1、详情链接和关联卡片。
7. 内容审核通过后再走审核/发布流程。停用、撤回或 `noindex` 的内容不会作为正常公开可检索页面。

修改已有产品时，先记录原值；不要为了搜索命中而改产品名、塞关键词、发布不完整草稿或改真实参数。

## 5）产品参数如何修改

入口：“产品与目录”→“产品规格”，或从产品编辑页进入规格关系。

1. 先选择产品，再选择规格组或已有规格记录。
2. 参数名称、值、单位、排序和备注分开填写，不要把单位重复写进数值字段。
3. 中英文参数名称和备注分别维护；数值必须与批准资料一致。
4. 新增规格后检查排序；删除前确认没有页面或资料仍依赖该项。
5. 保存后做 fresh GET：刷新页面或重新打开记录，确认值、单位和顺序未丢失。
6. 再打开对应产品前台详情，核对规格表的显示。

没有批准的真实参数时保留 Demo 标记，不要猜测公差、材质、硬度、产能或工艺窗口。

## 6）案例、知识文章、FAQ 如何维护

### 客户案例

入口：“客户案例”。填写双语标题、摘要、正文、图片、关系和 SEO。真实客户名称、Logo、项目结果、图片和数据必须先取得公开授权；未授权时不要录入，更不能只在显示端隐藏。

### 知识文章

入口：“知识文章”。选择文章类型，填写双语标题、摘要、正文、作者、审核人、来源、相关产品/材料/工艺及 SEO/GEO。技术结论必须有批准来源和审核人；“能生成 JSON-LD”不代表内容已获专家认证。

### FAQ

入口：“常见问题”。填写问题、答案、语言、排序和状态。答案应解决一个明确问题，不要堆关键词。涉及技术参数、承诺或法规时先由负责人审核。

三类内容都按“保存草稿→重新打开→预览→审核→发布→前台复核”执行。中英文内容不能依靠自动翻译直接发布。

## 7）媒体资源库如何上传与复用

入口：“媒体资源库”。

1. 点击“新上传”，选择允许的文件，上传后会生成新的媒体记录；不会自动替换旧文件，也不会自动改动页面引用。
2. 从列表选择刚上传的记录，填写中文和英文 Alt、标题、图注。
3. 设置公开可见性和处理状态时，要符合用途。只有公开且处理完成的图片可供首页轮播选择。
4. 保存元数据后重新选择该记录，确认双语信息已回填。
5. 到产品、首页或文章编辑页选择这条媒体记录进行复用。
6. 替换页面图片时，应改“页面与媒体的关联”，不要把同一媒体记录误当成文件覆盖功能。

不要上传客户图纸、私有 RFQ 附件、客户身份信息、后台备注或未批准资料到公开媒体库。

## 8）下载资料如何维护

入口：“下载资料”。

1. 先在媒体库准备合格文件，再新建下载资料。
2. 选择文件，填写中英文标题、说明、版本、发布日期、排序和状态。
3. “启用”表示符合其他公开条件时可显示；“停用”应从公开下载入口排除。
4. 保存后从接口回读，重新打开记录核对文件与双语标题。
5. 在前台“资料下载”页实际点击一次，确认状态码、文件名和文件可打开。

当前三份 PDF 是 Demo 文件，不代表正式产品手册、工艺标准或公司承诺，正式上线前需替换。

## 9）SEO / GEO 字段怎么填

SEO 字段用于搜索结果和页面摘要；GEO 字段用于把已批准的内容组织得更清楚，不会自动把内容变成权威事实。

- SEO title：准确写页面主题和品牌，避免重复、夸张和关键词堆叠。
- SEO description：用一两句话说明页面能提供什么信息，不写无法证明的承诺。
- Canonical：通常由系统和正式域名规则控制，不要用 Demo 域名替换正式 canonical。
- Noindex：按页面自身政策设置。外层 Demo 全站 noindex 与单页 SEO 状态是两层不同保护。
- GEO 摘要/要点：只写正文中可验证、已有来源或已审核的事实。
- 来源：填写可追溯的批准资料，不要把自动生成文本当成来源。
- 作者/审核人：只能关联真实、已批准公开的身份。

固定 Products、Contact、RFQ 页面可从左侧对应 SEO 页面修改。Contact 和 RFQ 后台会分别显示“内容发布状态、页面访问状态、页面搜索引擎规则、环境保护”，不要只看 Route 是否启用就理解为“业务可索引”。当前 Contact/RFQ 仍为 noindex。

## 10）询盘中心怎么查看

入口：“询盘中心”。

1. 可按询盘状态、关键词等条件筛选并分页查看已有记录。
2. 点击一条记录查看详情前，确认自己有相应权限。
3. 客户姓名、联系方式、需求、附件和内部备注都属于私有信息，不得复制到公开页面、搜索摘要或证据包。
4. 当前 Demo 因 Privacy 未发布而禁用 RFQ 提交，所以“暂无询盘”是预期状态，不是故障。
5. 不要为了测试而在常驻 Demo 创建虚构询盘、上传客户附件或触发邮件。

## 11）发布、草稿、启用/停用等状态说明

- 草稿：仅后台保存，普通前台不应显示。
- 已审核：内容经过相应审核动作，但不一定已发布。
- 已发布：Publication 已进入发布状态，还要同时通过语言、Route、时间、SEO、Privacy 和实体资格检查才会公开。
- 已撤回：不再作为正常公开内容显示。
- 启用：某个对象或入口允许使用；不等于已经发布，也不等于可被搜索引擎索引。
- 停用：对象不应参与公开展示或正常选择。
- 页面访问状态：Route 是否让访客访问该页面。
- 页面搜索引擎规则：该页面自己的 index/noindex 规则。
- 环境保护：Demo 外层的全站 noindex、no-store、Sitemap 404 等保护。
- 应用布局：首页把已保存草稿复制为当前普通首页布局；必须在预览和审核后执行。

当前 Demo 的正确保护状态：HTTPS、前台无 Basic 弹窗、后台登录与权限保护、全站 noindex/no-store、Sitemap 404、Privacy 不发布、RFQ 不提交。

## 12）常见错误与排查建议

### 保存失败或 revision 冲突

不要继续覆盖。重新读取页面，比较他人或另一窗口的修改，再重新编辑。

### 图片不在轮播选择列表

检查媒体是否为图片、是否公开、是否处理完成。私有、处理中、失败或非图片文件不会出现。

### 按钮链接保存失败

按钮文案与链接应同时填写；链接必须是当前站点绝对路径，以 `/` 开头，不能写 `javascript:`、外站 URL 或通配符。

### 前台没看到修改

依次检查：是否保存草稿、是否应用/发布、是否选对语言、模块/轮播项是否启用、Publication 和 Route 是否满足公开条件。最后强制刷新并重新打开页面。

### 中英文内容串了

立即停止编辑，回到语言标签核对。每种语言单独保存；不要把中文复制到英文后直接发布。

### 搜索没有命中

先确认记录是真实公开、同语言、已发布且页面可见。不要靠改名称、塞关键词或发布草稿制造命中。

### 401 / 403 / CSRF 错误

重新登录并检查账号权限；关闭旧登录页再试。不要绕过 CSRF 或修改浏览器 Cookie。

### 页面显示 noindex

Demo 外层 noindex 是预期保护。单页还可能有自己的 noindex；不要为“看起来通过”而关闭环境保护。

### 操作后不确定是否成功

执行“保存→fresh GET（刷新/重新打开）→前台预览”。没有回读证据时，不要继续下一次覆盖。
