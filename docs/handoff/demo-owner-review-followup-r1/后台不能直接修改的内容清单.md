# Demo R2 后台不能直接修改的内容清单

审计基线：`junhui-demo-r2 / phase-3.7`，本轮运行版本  
审计口径：这里的“不能直接修改”包括代码/配置/初始化项、缺少后台入口的结构，以及虽有字段入口但员工无法凭空产生或批准的真实资料。  
优先级口径：P0 表示正式上线前必须解决，不表示当前受保护 Demo 故障；P1 建议尽快改造或替换；P2 可在后续迭代处理。

## 结论

共识别 **50 项**：**P0 21 项、P1 20 项、P2 9 项**。

- 真正写死在代码、配置、初始化脚本或页面结构中的项目：38 项（FE、BE、SD、ST、AD）。
- 需要 Owner 提供、审核或授权的真实资料包：12 项（RM）。这些字段中有一部分已经可以在后台编辑，但后台不能替公司创造真实性、授权和政策批准，所以仍属于上线前不可由员工独立完成的内容。

## 优先替换建议

### P0：正式效果或接单安全的前置条件（21 项）

优先顺序建议：

1. 先批准 Privacy、RFQ 收件人/保留期/同意版本及安全配置（FE-09、BE-04、AD-04、RM-12）。
2. 再提供公司主数据、品牌资产和真实联系方式（FE-01、AD-01、RM-01）。
3. 提供产品、规格、技术能力、设备、证书、案例授权和专家资料（SD-02、RM-02/03/04/06/07/08）。
4. 用批准真实媒体替换生成图及轮播图，替换 Demo 视频/PDF（SD-03/04、RM-09）。
5. 建立正式环境独立安全/SEO配置，保持 Demo 不变（BE-01/02/03、AD-03）。

### P1：建议尽快处理（20 项）

主要是导航/页脚管理、首页模块扩展规则、SEO/结构化数据、发布状态解释、语言、权限工作流、搜索白名单运营、媒体关系、后台工作流、重定向和剩余正式知识/视频/PDF资料。它们不会阻断当前受保护 Demo 复验，但会影响长期运营效率或正式内容完整度。

### P2：后续再处理（9 项）

主要是 UI 词条、页面模板、卡片布局、轮播高级样式/节奏、重定向底层策略、首页初始注册表和三类组件结构。当前实现已有稳定默认值，不建议在 Owner Review 阶段扩大改造。

## 本轮已经解决、因此不再列为缺口的事项

- Hero 轮播的图片、双语标题/副标题、CTA、内部链接、排序、启用/停用，已经能从“首页编排”后台维护。
- 后台支持新增、修改、删除、上移/下移、媒体库选择、认证预览与中英文切换。
- 普通首页支持桌面/移动适配、自动播放、手动切换和暂停，并保留原 14 模块。

尚未开放的是 AD-07 所列“高级视觉/播放参数”，这是本轮有意保留的设计边界，不影响员工维护轮播内容。
