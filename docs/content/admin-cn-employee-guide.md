# 骏辉 Demo 中文后台员工使用说明

## 1. 日常入口

- 演示官网中文：<https://demo.junhuiscrewbarrel.com/zh-cn/>
- 演示官网英语：<https://demo.junhuiscrewbarrel.com/en/>
- 演示后台：<https://admin-demo.junhuiscrewbarrel.com/>

请保持现有本地域名预览服务运行。前台不会出现 Nginx Basic Auth 弹窗；后台仍需使用应用账号登录。不要把 Demo 内容用于生产发布或对外承诺。

## 2. 界面约定

- 操作界面固定使用简体中文，包括按钮、状态、弹窗、分页和错误提示。
- 编辑英语内容时，字段标签和操作按钮仍是中文，业务正文保持英语。
- slug、Locale、型号、单位和权限代码属于技术标识，不翻译、不随意修改。
- 列表以中文标题、名称或问题为主，编号和英语标题用作辅助识别。

## 3. 内容编辑的标准步骤

1. 从左侧导航进入对应模块。
2. 在左侧列表选择记录；先确认中文标题和辅助编号。
3. 选择“中文”或“英语”语言标签。
4. 在“基本信息”“内容”“媒体”“关系”“SEO/GEO”等分组中修改需要的字段。
5. 正文可使用基础 Markdown，并在预览区检查排版。
6. 点击保存后等待 fresh GET 完成；再刷新页面并重新打开该记录确认。
7. 需要生命周期操作时，只使用账号已有权限；不要绕过审核或伪造发布人。

如果当前有未保存修改，切换记录或语言会出现离开确认。选择取消可继续编辑；选择继续会放弃当前未保存内容。快速切换时后台会丢弃过期请求结果，避免把上一条记录的正文显示到新记录中。

## 4. 常用模块

### 产品与内容

- 产品、分类、材料、工艺、应用、方案：在 Catalog 分组维护。
- 案例、知识、FAQ、作者：在内容分组维护。
- 选择现有记录后编辑真实数据库内容；不要在浏览器临时数据中制造“保存成功”。
- 中文更新不会自动清空英语；切换语言后仍应人工检查英语值。

### 企业资料与制造能力

“企业与信任”总览按企业资料、制造能力、设备、证书、专利、荣誉、展会分组。界面中的英文权限或类型代码只用于技术核对，不是员工的主导航。

### 媒体

- “修改元数据”：只改标题、alt、说明等，不替换文件。
- “替换指定位置媒体”：把现有引用位置换成另一项媒体。
- “上传新文件”：创建新的媒体对象。

已批准产品图片是只读复用素材；不要覆盖原文件或绕过引用保护。询盘附件属于私有文件，不能当普通公开媒体处理。

### 询盘

- 可按关键词、中文状态、负责人和日期筛选。
- 时间按北京时间显示。
- 列表分页是真实服务端分页；清除筛选后再判断记录是否缺失。
- 本 Demo 的正式询盘提交仍禁用，不发送邮件，不上传真实客户附件。

### 角色权限

按中文业务分组查看权限矩阵。权限代码用于开发和审计核对；员工不要直接以代码判断业务含义，也不要扩大自身权限。

## 5. 页面状态说明

- 未选择：请先从列表选择一条记录。
- 新建：表示正在填写尚未保存的记录。
- 加载中：等待真实 API 返回，不要重复连续点击保存。
- 编辑中：当前表单已绑定所选记录。
- 空数据：先检查筛选条件和权限，再报告问题；不要清库重导。
- 无权限：联系管理员分配已有角色，不要创建免登录入口。
- 错误：保留页面、操作步骤和时间，先重试一次；持续失败再交给维护人员。

登录过期时系统会自动尝试一次安全刷新。刷新成功后原请求继续；刷新失败则返回登录页，不会用前端假数据代替。

## 6. 前台复核方法

保存内容后至少完成以下检查：

1. 刷新后台并重新打开记录，确认 fresh GET 值正确。
2. 打开对应中文和英语前台页面，确认首次页面内容与后台一致。
3. 点击语言菜单，确认仍留在 `demo.junhuiscrewbarrel.com`。
4. 涉及图片时滚动到图片并确认可显示、alt 正确；涉及视频时实际播放数秒。
5. 涉及 RFQ 时只检查入口和禁用提示，不提交真实询盘。

当前 Demo 全站保持 `noindex`，Sitemap 关闭。Privacy 尚未发布；不要用空白页面或取消同意项来假装完成。

## 7. 禁止事项

- 不覆盖原 phase37 已批准公司、产品、SEO 或 Privacy 数据。
- 不连接生产、腾讯云、Gmail、NAS 或 Analytics。
- 不修改公共 DNS，不建立公网隧道。
- 不清卷、清库、重导或运行默认 Seed。
- 不使用真实客户资料、图纸、附件或邮箱内容做 Demo。
