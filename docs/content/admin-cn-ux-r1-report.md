## 2. 主要工程改动

### 2.1 统一中文界面词汇

- 新增集中式中文显示工具，统一发布状态、询盘状态、角色、权限分组、布尔值及北京时间格式。
- 应用外壳、导航、登录、无权限页、工作台和系统页使用统一中文标题。
- 浏览器标题改为中文，例如“工作台 · 骏辉全球官网后台”“首页模块编辑器 · 骏辉全球官网后台”“隐私说明管理 · 骏辉全球官网后台”。
- 只转换显示文案，接口枚举值和权限代码没有变更。

### 2.2 运营型列表与编辑器

- Authority 类内容列表新增服务端中文优先投影：`display_title`、英语辅助标题及翻译数量。
- 产品、分类、材料、工艺、应用、方案等 Catalog 列表同样使用真实中文名称投影。
- 表单按基本信息、内容、媒体、关系、SEO/GEO、发布历史分组。
- 标题改为正常单行输入；正文提供基础 Markdown 编辑和预览。
- 未选择、新建、加载、编辑、错误、空数据、无权限状态分别显示明确中文信息。
- 选择其他记录或语言前检测脏表单，弹出“当前有未保存的修改，离开后将丢失。是否继续？”确认。
- 使用请求序号隔离快速切换响应，避免旧请求覆盖新选择；保存后执行 fresh GET，再刷新并重新打开验证。

### 2.3 询盘、权限与媒体

- RFQ 后端增加服务端分页及主题/联系人/公司/邮箱搜索、状态、负责人和日期过滤。
- 询盘时间统一显示为北京时间；内部状态值保持英文枚举。
- 角色权限改为中文业务分组矩阵，权限代码保留在次要说明中，未扩大任何权限。
- 媒体页明确区分“修改元数据”“替换指定位置媒体”“上传新文件”，并保留已批准素材只读提示和私有附件边界。

### 2.4 登录恢复

- 修复后台访问令牌过期后的恢复链路：客户端单飞刷新、CSRF Cookie 更新以及数据请求的一次 401 重试。
- 真实浏览器强制令牌过期后观察到 `/auth/me` 返回 401、`/auth/refresh` 返回 200、原数据请求随后返回 200。
- 后台应用登录、RBAC、CSRF、Secure Cookie 均保留；没有创建免登录管理员或写死 Token。
